1. OVERVIEW
--------------------------------------------------------------------------------
Concerto is a deterministic, measurable stereo-to-surround (5.1 and 7.1)
upmixing engine designed for audiophile and studio restoration workloads.
It pairs an active C++20 matrix DSP core (~40x–50x realtime throughput) with
a Qt6 desktop workstation and a scriptable CLI.

This v0.1.0-alpha release represents the completion of Milestones 1, 2, 3,
and Milestone 4 (Stage a), delivering full DSP-first upmixing, adaptive
transient-aware envelope control, flag-gated neural vocal center isolation
via Demucs (htdemucs / PyTorch), and a standalone Windows desktop GUI.

--------------------------------------------------------------------------------
2. KEY FEATURES & HIGHLIGHTS
--------------------------------------------------------------------------------
- Native C++20 DSP Acceleration:
  Radix-2 float64 FFT, 3-stage cascaded all-pass decorrelation banks,
  Butterworth SOS band-limiting (150 Hz–8 kHz), and chunk-based rendering.
  Renders at 40x–50x realtime (approx. 0.002s per second of 48 kHz audio).
  Auto-discovered via ctypes with pure-Python fallback.

- Deterministic Adaptive Controller:
  Signal-adaptive stereo cross-feed parameter beta(t) in [0.15, 0.90] steered
  by side-dominance directness (tau = 1.5s). Dual-timescale transient envelope
  protection (tau = 50ms) dives decorrelation to floor at attacks to eliminate
  spatial smearing.

- Strict Front Channel Preservation:
  Front channels (FL/FR) remain bit-identical to the original stereo recording
  prior to output quantization (E_L = E_R = 0). MPEG fold-down reconstruction
  SDR exceeds 20 dB on real-world material (well above the 10 dB specification).

- Neural Vocal Centre (PyTorch / Demucs):
  Flag-gated (--ai on) htdemucs vocal separation paired with a strict 4-point
  acceptance harness:
    * Timeline alignment lag <= 4 samples
    * Recombination residual >= 20 dB below mix
    * Transient envelope jump <= 3.0
    * Stereo correlation floor >= -0.95
  Stems meeting criteria drive a smoothed vocal gate schedule (V) to anchor
  the center channel while keeping front stereo imaging untouched.

- Desktop GUI Workstation (PySide6 / Qt6):
  Modern dark-mode interface featuring 8 specialized workspaces:
    1. Render Studio & Batch Queue: 5.1/7.1 render, streaming mode, peak monitor.
    2. Stereo Analysis Lab: Real-time pyqtgraph STFT curves (rho, gamma2, directness),
       Lissajous stereo vectorscope, polar phase meter, M/S balance.
    3. Acceptance & Validation Suite: 10-point automated QA criteria.
    4. Multi-Profile Benchmark: Comparative table (Peak, Surround RMS, Coherence).
    5. AI Stem Lab: Solo stem auditioning with waveform/envelope displays.
    6. Speaker Routing: 8-channel calibration tone generator & visual speaker map.
    7. Preset Studio: Live visual editor for TOML DSP profiles.
    8. Diagnostics: C++20 core detection and hardware device enumeration.
  Persistent audio transport bar with real-time MPEG fold-down headphone preview.

- Comprehensive Container Layout Mapping:
  Automatic channel ordering per container standard (FLAC 6ch/8ch, WAV/WAVE 6ch/8ch)
  defined in concerto/audio/layouts.py.

3. RUNNING THE APPLICATION
--------------------------------------------------------------------------------
Option A: Running from Source
  # Install dependencies
  pip install -r requirements.txt
  pip install -r requirements-gui.txt
  pip install -r requirements-ai.txt  # Optional: for neural vocal centre

  # Launch GUI
  python -m concerto gui
  # or
  python run_gui.py

  # Run CLI commands
  python -m concerto render input.flac --layout 7.1 --mode adaptive --out output.flac
  python -m concerto analyse input.flac --out reports/
  python -m concerto validate output.flac --reference input.flac

Option B: Standalone Windows Binary
  Run the pre-packaged executable directly without requiring a Python environment:
  dist\concerto-gui\concerto-gui.exe

Option C: Building the Standalone Executable
  python scripts/build_gui.py

Option D: Rebuilding the Native C++20 Core
  cmake -S native -B native/build -DCMAKE_BUILD_TYPE=Release
  cmake --build native/build
